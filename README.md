# kultra-mega-stores-sql-analysis
SQL Server Analysis of Kultra Mega Stores Data, covering regions, product categories, customer segments, shipping cost, business insights.

:pushpin: This project analyzes sales data from Kultra Mega Stores (KMS), a retail company, using SQL Server. The goal was to answer key business questions from management about product performance, regional sales, customer segments, and shipping costs, then turn the results into recommendations that could improve profitability
